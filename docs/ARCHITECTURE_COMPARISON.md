## 2. 地圖投影與製圖學數學模型

### 2.1 原版實作問題：未校正的投影形變
原版使用標準麥卡托投影公式：
$$y = \ln\left(\tan\left(\frac{\pi}{4} + \frac{\text{lat} \cdot \pi}{360}\right)\right)$$
在畫布座標轉換時，原版直接依據畫布寬高與預設經度跨度進行簡單縮放。由於未針對日本列島所在的北緯 30°~45° 進行垂直／水平比例的局部等角校正（Conformal Ratio Correction），導致日本形狀在不同視窗比例下容易產生縱向壓扁或拉長的失真。

### 2.2 台灣版創新：1:1 嚴格等角麥卡托（True Conformal Mercator）
在以台灣（緯度 21.8°N ~ 25.3°N，中心緯度約 23.6°N）為核心的座標系中，麥卡托投影的局部微分尺度比為：
$$\frac{dy}{d\phi} = \frac{1}{\cos(\phi)}$$
在北緯 23.6°（北回歸線附近），理想要素比為：
$$\text{Aspect Ratio} = \frac{1}{\cos(23.6^\circ)} \approx 1.0913$$

台灣版在 `index.html` 與測試腳本中實作了精準的雙向換算：
```javascript
function merc(lat) {
  lat = Math.max(-85, Math.min(85, lat)) * Math.PI / 180;
  return Math.log(Math.tan(Math.PI / 4 + lat / 2));
}
function invMerc(y) {
  return (2 * Math.atan(Math.exp(y)) - Math.PI / 2) * 180 / Math.PI;
}

// 嚴格依據畫布像素長寬比動態計算 Y 軸弧度範圍，保證水平 1 度與垂直 1 度之幾何長度在經緯度中心點完美等長
const ySpanRad = (H / W) * (LONW * Math.PI / 180);
const MY = yCenterMerc + ySpanRad / 2;
const MN = yCenterMerc - ySpanRad / 2;
```
此演算法確保台灣經典的「甘藷（番薯）」地形在手機直向、平板或電腦橫向螢幕上，幾何輪廓**永遠維持 1:1 零畸變**。

## 4. 物理模擬引擎與板塊運動力學

### 4.1 徹底消除「板塊自動漂移噴飛 Bug」
- **原版缺陷：** 
  原版啟動時，若日本列島邊緣因坐標計算與歐亞大陸多邊形有 1 個像素的初始重疊，`pushLand()` 物理反作用力函式會在第一幀判定為剛體碰撞，賦予歐亞大陸極大加速度向量（`B.vx`, `B.vy`），導致遊戲一開局玩家還沒動，後方的中國大陸與俄羅斯板塊就以火箭般速度自行向左上方「噴飛漂移」。
- **台灣版工程修正：**
  1. **座標系剛性校準：** 重新校正台灣島起始座標與周邊板塊相對間距，進行單元測試嚴格斷言開局 60 幀內 `initialCollisions === 0` 且 `maxDrift === 0`。
  2. **大陸板塊錨定與質量阻尼：** 將歐亞大陸等超大型板塊設定為「重質量錨定實體」，具備極大靜摩擦係數，杜絕陸塊自動漂移的荒謬現象。

### 4.2 平滑慣性與阻尼滑動 (Momentum & Damping)
台灣版在玩家放開觸控或方向鍵時，賦予島嶼自然的流體慣性滑動感：
$$v_{t+\Delta t} = v_t \cdot k^{\Delta t} \quad (k = 0.12)$$
使這艘「三萬六千平方公里不沉航母」在海洋漂移時兼具厚重質量感與靈動操舵手感。

## 7. 空間碰撞判定與登陸地標診斷系統

### 7.1 射線法多邊形內點檢測 (Optimized Ray Casting)
```javascript
function inPoly(pt, ring) {
  var x = pt[0], y = pt[1], inside = false;
  for (var i = 0, j = ring.length - 1; i < ring.length; j = i++) {
    var xi = ring[i][0], yi = ring[i][1], xj = ring[j][0], yj = ring[j][1];
    if ((yi > y) !== (yj > y) && x < (xj - xi) * (y - yi) / (yj - yi) + xi) inside = !inside;
  }
  return inside;
}
```
台灣版採用 AABB 外接矩形包圍盒預篩（Bounding Box Pre-check），僅在颱風接近島嶼半徑 $R + 120\text{px}$ 內時才計算 562 個節點的多邊形射線，確保 60 FPS 零掉幀。

## 9. CWA 氣象雷達可視化渲染管線

### 9.1 原版：平淡同心圓
原版颱風僅由 2 個純色圓圈組成：外圍細圓代表暴風圈，中心小實心點代表颱風眼。

### 9.2 台灣版：專業 CWA 氣象雷達回波合成
台灣版在 Canvas 渲染管線上重新定義了氣象雷達層：
1. **7 彩反時針旋轉氣旋螺旋雨帶：**
   - 依據對數螺旋線公式 $r = a \cdot e^{b\theta}$ 即時生成 4 條對稱旋臂。
   - 旋轉角隨時間持續更新：`rot += (spd * 1.8) * dt`。
