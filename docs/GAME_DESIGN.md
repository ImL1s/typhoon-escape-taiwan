## 1. 核心概念與玩家心智模型

### 1.1 遊戲世界觀
每當夏天西北太平洋海溫升高，台灣便成為熱帶氣旋的兵家必爭之地。在本作中，玩家扮演「全島總指揮舵手」，直接操縱長 394 公里、面積 3.6 萬平方公里的整座台灣島及周邊澎湖群島、綠島、蘭嶼、小琉球與龜山島。

在大洋中，玩家不再是被動等待氣象局宣佈停班停課的受災居民，而是可以靈活蛇行、漂移轉向，甚至利用島中央高聳入雲的**中央山脈（護國神山）**主動切碎颱風結構的強悍島民！

### 1.2 核心情緒體驗
- **緊張刺激：** 巨大雷達回波狂暴逼近，警報聲迴盪，毫釐之差躲過毀滅性眼牆。
- **掌控感：** 親自開著自己的家鄉在海圖上瀟灑漂移甩尾。
- **在地共鳴與幽默：** 滿滿的「高麗菜一顆 280 元」、「KTV 官網塞爆」、「放颱風假買泡麵」等台灣人秒懂的集體文化記憶。

## 2. 四大設計基石 (Core Pillars)

1. **台灣本土靈魂 (Authentic Taiwanese Identity)：**
   每一處海岬、每一座離島、每一句新聞快訊與每一項稱號，皆深深扎根於台灣的地理與生活文化。
2. **極致微操反饋 (Micro-tactile Response)：**
   零延遲、高靈敏度的觸控與鍵盤反應，配合流暢的慣性阻尼，讓玩家享受如絲般順滑的航海躲避樂趣。
3. **動態氣象仿真 (Meteorological Realism)：**
   嚴謹的 1:1 等角麥卡托投影，結合中央氣象署規範的 5 階雷達螺旋回波與 72 小時潛勢預報錐，呈現專業氣象轉播視覺。
4. **零阻力即刻遊玩 (Instant Zero-Friction Play)：**
   單一檔案、零外部請求、雙擊即玩、極速重啟，提供令人停不下來的「再戰一局」中毒性。

## 4. 操作體系與人機工學規範

### 4.1 手機／平板觸控體驗
- **全螢幕任意拖曳（Full-screen Drag）：** 
  無須拘泥於特定位置，手指在螢幕任何海域觸控滑動，台灣島即以流暢的彈性牽引跟隨移動。
- **人體工學虛擬方向盤（Ergonomic Virtual Joystick）：**
  固定於左下角，高度透過動態計算永遠置於跑馬燈上方，不遮擋警報文字，半徑受限於 $38\text{px}$ 內，反饋靈敏。

### 4.2 電腦端鍵盤與滑鼠
- **方向導航：** 支援 `W` `A` `S` `D` 以及方向鍵 `↑` `↓` `←` `→`。
- **快節奏暫停與重啟：**
  - 按 `Space`（空白鍵）：開始遊戲 ➔ 暫停／繼續 ➔ 死亡後立即再戰下一局。
  - 按 `P` 鍵：切換暫停狀態。
  - 按住滑鼠左鍵拖曳亦可無段導航。

## 5. 護國神山策略深度：風險與報酬

### 5.1 機制設計意圖
在原版遊戲中，玩家唯一的手段就是「逃跑」。但在台灣大逃亡中，我們引入了「**以地形反制颱風**」的積極進攻策略！

### 5.2 數值平衡模型
- **防禦生效條件：** 颱風暴風圈掠過中央山脈脊樑（16 點控制軸線），且颱風眼核心未進入島嶼多邊形。
- **破壞率：** 每秒削減當前颱風峰值暴風半徑的 $35\%$。
- **風險對賭（Risk vs. Reward）：**
  - 玩家若完美掌控距離，讓颱風西側環流被中央山脈「刮」個 2~3 秒，颱風就會萎縮成人畜無害的輕度低氣壓，大幅騰出海域空間。
  - 若稍微手滑距離過近，颱風眼核心一旦擦到海岸線，立即宣告滅頂登陸！

## 8. 存活評價與六階認證稱號體系

依據生存天數（以每日約 1 秒推進之遊戲時鐘）進行階層判定：

```
[0~5 天]   泡麵還沒買好          ➔ 剛出航就慘遭穿心颱登陸，連泡麵水都還沒煮開。
[6~15 天]  中央山脈實習生        ➔ 懂得用東側山脊磨蹭颱風，具備基礎避難常識。
[16~29 天] 颱風假精算師          ➔ 熟悉每顆颱風路徑，精準預判風雨走向。
[30~49 天] 護國神山防衛隊長      ➔ 成功瓦解多顆強颱，神山結界運用得心應手。
[50~74 天] 開著台灣島漂移的航海王➔ 在狂暴太平洋與南海間蛇行甩尾的傳奇舵手。
[75+ 天]   太平洋不沉航母．台灣之神 ➔ 超越氣象學極限，整座島就是大洋上的不沉神話！
```
